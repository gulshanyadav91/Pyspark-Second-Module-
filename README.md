# PySpark – Second Module

Hands-on practice notebook for the second module of my PySpark learning journey. It builds on the basics (SparkSession, DataFrames) and works through practice problems in a Jupyter notebook.

## Repository contents

| File / Folder | Description |
|---|---|
| `Pyspark_module_2.ipynb` | Main notebook with PySpark code and practice problems |
| `anaconda_projects/` | Anaconda project files (auto-generated) |
| `.ipynb_checkpoints/` | Jupyter autosave checkpoints (auto-generated) |

## Prerequisites

- Python 3.9 or higher
- Java 8, 11, or 17
- PySpark (`pip install pyspark`)
- Jupyter Notebook, or VS Code with the Jupyter extension

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/gulshanyadav91/Pyspark-Second-Module-.git
   ```
2. Install the dependencies:
   ```
   pip install pyspark ipykernel
   ```
3. Open `Pyspark_module_2.ipynb` in Jupyter or VS Code and run the cells in order with `Shift+Enter`.

## Topics practiced

- Creating a SparkSession and DataFrames
- Selecting and filtering data
- Sorting, adding columns, and removing duplicates
- Grouping and aggregations
